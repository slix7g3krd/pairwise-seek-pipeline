# pairwise-seek-pipeline

播放器拖动进度条，音乐从头爆一声，视频切下一段又对不上口型：音频 seek 只改解码位置，没有重置重采样器和缓冲；seek 后时间戳从 0 重新算，和视频 PTS 错位；交叉淡入淡出在 seek 时仍跑旧曲线，音量先降后爆；流式解码的环形缓冲没清空，旧样本混进新位置；可变帧率音频的时间基换算没重算，长播后漂移；seek 到关键帧前，解码器从更早位置开始但没丢弃前置样本；多轨音频只 seek 主轨，评论轨还停在旧位置；硬件解码器 seek 异步返回，界面已显示新时间；seek 过程中的暂停/恢复没有合并，重复请求打乱顺序；音频时钟和视频时钟各自 seek，恢复后不同步；缓存按文件路径，换音轨后仍用旧 PCM；seek 后的字幕/章节时间没跟着更新；网络流 seek 触发重新缓冲，缓冲期间时钟继续走。audio/seek_pipeline.py 是核心，tests/test_seek_pipeline.py 15个红。要修的是：解码重置；时间戳；淡入淡出；缓冲清空；时间基；前置丢弃；多轨；异步确认；请求合并；音视频时钟；缓存隔离；字幕同步；缓冲时钟。

## 运行

```bash
python -m pytest tests -q
```
